Configurar Google Drive

Para sincronizar necesitas crear un proyecto en Google Cloud (gratis). Sigue estos pasos:

  1. Ve a console.cloud.google.com
  2. Crea un nuevo proyecto (ej: "Finanzas")
  3. En el menu lateral: APIs y servicios → Biblioteca → busca y activa Google Drive API
  4. Ve a Credenciales → Crear credenciales → ID de cliente OAuth
  5. Tipo: Aplicacion web
  6. En "Origenes de JavaScript autorizados" anade la URL donde alojas la app (ej: https://tuusuario.github.io)
  7. Copia el Client ID y pegalo aqui abajo
